<objective>
Harden the local server before it ever holds a key.

CONCERNS.md is blunt about today's state: `cors({ origin: '*' })` and `serve({ port })`
with no hostname expose every route to any process that can reach the port — on a
laptop that is any browser tab, and on a shared network it is anyone on the LAN.
The routes so exposed include `POST /api/materials/repo`, which walks any readable
directory and stores it where the model and the API can read it. Phase 2 is when
provider keys land in this process. This is the last quiet moment to close it.

Per D-09 the web app gets the token injected at serve time and no endpoint ever
hands it out. Per D-12 loopback is the default with a gated, loud opt-in so the
home-server case stays alive without weakening anything. And the version string
gets a single source on the way past, because `scripts/doctor.mjs` currently
prints a version that matches nothing in git.

Purpose: FOUND-06's binding, Host, Origin and token half.
Output: one middleware, one token file, one version, and a test that proves a
request without the token does not get in.
</objective>

It performs three checks in order and returns a lowercase `{ error }` body on each failure. First, the request path: `/api/health` is exempt and returns early, because `scripts/doctor.mjs` and both test harnesses poll it and Phase 7 needs it reporting the version. |----------|-------------|
| any local process or browser tab -> HTTP API | today the whole API is reachable by any process or any page on the machine, and on a shared network by anyone on the LAN |
| network interface -> server | `serve()` currently binds every interface |
| token file -> consumers | the browser (via injected HTML), the Vite dev proxy, the stdio MCP server and the plugin hook all need it |
