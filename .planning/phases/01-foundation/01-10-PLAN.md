## Why this plan is wave 2 and not wave 1

Its task 2 runs the whole-tree gate — `pnpm build` then `pnpm test`. That gate is
not scoped to this plan's files: it compiles the entire workspace into the shared
`server/dist` and `web/dist` and then spawns the built server. Two plans running
it at the same time do not merely race over the build directory, they each
observe a tree carrying the other's half-finished edits, so neither result means
what it says. Plan 01-09 runs the same gate, so the edge is declared rather than
justified: this plan waits for it. Plan 01-11 waits for this one for the same
reason. Serialising three small plans costs wall-clock; a gate that reports on a
tree nobody intended is exactly the defect this whole gap closure exists to
repair.
