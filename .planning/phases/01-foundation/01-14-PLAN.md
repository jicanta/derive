The verification report's verdict rests on one sentence: the residual "has to be

(`server/src/index.ts:1093`) — and `serveApp` then calls `issueSession`
unconditionally, so one request with no headers yields a working API
credential. That is a defensible engineering choice for a local-first app, and

failure being repaired here".
