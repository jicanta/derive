## Phase Goal

**As a** learner, **I want to** choose the provider and model that teach me inside the app, see what my machine already offers, store keys safely and test the connection, **so that** I always know which model is teaching me and nothing about the method changes when I switch.

(The ROADMAP `**Goal:**` line for Phase 2 is prose-form; the story above restates it without adding anything.)

## Acceptance Criteria (phase, from ROADMAP success criteria)

- [ ] SC1 — pick a provider and a model, restart, same choice active (this plan)
- [ ] SC2 — key pasted once, masked, 0600 file, never echoed (plan 02)
- [ ] SC3 — logged-in CLIs, env keys as "set from environment", local servers on default ports (this plan: logins and ports; plan 02: environment)
- [ ] SC4 — fetch models or type an id, curated default preselected (plan 03)
- [ ] SC5 — test connection with the provider's own failure sentence; provider · model in the header and the plugin start message (plan 03, plan 04)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/settings* | Settings writes arrive from the page; the existing /api/* guard (Host, whole-string Origin, derive_session cookie or x-derive-token) fronts every new route |
| server → local ports 11434/1234/8080 | Detection probes loopback services the server does not control; a foreign process may answer |
| server → `claude auth status` | A child process whose JSON carries the learner's identity |
| settings table ← any same-uid process | derive.db is 0644; a stored value can be edited outside the API |
