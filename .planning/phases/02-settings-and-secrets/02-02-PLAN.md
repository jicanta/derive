## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → PUT /api/settings/:provider (key) | The one path a key enters the server; behind the existing /api/* guard |
| server → ~/.derive/secrets.json | A 0600 file beside the 0644 database; readable by any same-uid process |
| process environment → server | Operator-set keys that outrank the file |
| server → every egress (events, SSE, vault, logs, errors) | Where a key must never appear |
