<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server → provider hosts (api.anthropic.com, api.openai.com, generativelanguage.googleapis.com, openrouter.ai) | The only egress a stored key ever takes; fixed catalogue strings |
| server → learner-supplied base URL (OpenAI-compatible, local rows) | A destination the learner typed through an authenticated route; loopback and LAN allowed by design |
| provider response → browser | Error bodies may echo the request, including the key |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-14 | Information disclosure | Key echoed in a provider error reaching the browser | high | mitigate | `registerSecret` on load/set (plan 02) plus `safeMessage` on every sentence leaving probe.ts; the suite asserts both keys are absent from every response |
| T-02-15 | Information disclosure | Key exfiltrated by a redirect from a learner-set base URL to a third host | high | mitigate | `redirect: 'manual'` on every provider fetch; a 3xx is reported as a failure sentence and never followed; case in the suite |
| T-02-16 | Information disclosure | Gemini key in a URL query string landing in logs and proxies | medium | mitigate | `x-goog-api-key` header only; pure case asserts the URL has no `key=` |
| T-02-17 | Spoofing / SSRF | A learner-supplied base URL pointing at an internal service | medium | accept | Per CONTEXT discretion the learner's own endpoint is the point of the row; it is set only through the authenticated PUT (the model has no tool to set it), carries only that row's key, and the SSRF rules of Phase 1 D-10 apply to every other outbound fetch. Breadcrumb: canon SSRF review stays with /gsd-secure-phase |
| T-02-18 | Denial of service | A slow or hanging provider holding the event loop's request | low | mitigate | `AbortSignal.timeout` at 8 s remote / 4 s local; the routes are independent of turns |
| T-02-19 | Tampering | A provider's model id carrying characters into stored settings | low | mitigate | Fetched ids are display suggestions; a stored model still passes the PUT charset check from plan 01 |
| T-02-SC | Tampering | npm/pip/cargo installs | low | accept | No package installed in this phase |
</threat_model>
