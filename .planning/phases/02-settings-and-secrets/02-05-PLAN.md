| T-02-24 | Elevation of privilege | A learner override changing another learner's or the install's model | low | mitigate | The tier reads `getLearner(learnerId)` for the turn's own lesson; `GET /api/settings/active` resolves for the default learner when none is named (`learnerOf` falls back to `DEFAULT_LEARNER_ID`), so one learner's override never reaches another's resolve; case in the suite |
