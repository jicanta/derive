<objective>
**As a** learner paying per token, **I want to** have every lesson priced from a table I can read and override on my own machine, **so that** the cost Derive shows me is a figure I can check rather than one it fetched from somewhere.

This plan delivers the numbers the phase's cost slice is made of: the versioned price and context-window table, the learner's local override, the pure cost calculator with its one money formatter, and the conservative context estimator. The learner-visible increment — the figure in the lesson header and on the Home row — lands in plan 03-08, which wires these modules to the loop and to both screens.

This is the one horizontal cut this phase makes, and the reason is context cost, not preference: the cost slice touches ten files across the server and two pages, which cannot fit a single plan at two or three tasks. The pure half is split out because it is the half with no dependency on the loop, so it runs in wave 1 beside the tracer instead of extending the critical path.

Purpose: put every number this phase shows behind a pure module with no I/O, so the cost path cannot fail and a price change is a reviewable diff.
Output: `server/src/pricing.ts`, `server/src/prices.ts`, `server/src/cost.ts`, `server/src/context.ts`, `PRICES_PATH` in `server/src/config.ts`, and `server/test/cost.test.ts`.
