## Phase Goal

**As a** learner, **I want to** run Derive free and offline on a local model without the method silently degrading, prove any chosen model runs the method before I invest a session, and see what learning has cost across every provider, **so that** I am taught the Derive way on whatever model I have access to, with nothing lost between providers.

This plan delivers the refusal half of the second clause: a model that cannot call tools is refused with a plain message naming the missing capability, rather than producing a broken lesson.

<objective>
Read each local server's own metadata to decide whether a model can run the method, and refuse clearly when it cannot.

Purpose: every mechanic of the method is a tool call — the graph, the understanding gate, the quiz. A model that cannot call tools cannot teach, and discovering that halfway through a lesson costs the learner the lesson. The cheap answer is in the servers' own metadata; the definitive answer is one tiny round-trip; and the one thing that must never happen is reading an older build's silence as a refusal.

Output: `postJson`; `server/src/capability.ts` with three pure parsers, a three-valued verdict, the two-tier `capabilityOf`, the whole-list `capabilityList` and the remembered verdict the refusals read; a `POST /api/settings/:provider/capability` route; the whole-list pass on the detection route; the refusal on the model write and on the activation, so a model the ladder refuses cannot become the active one; the verdict on the row with the approved refusal copy; and the lesson-time backstop card.
</objective>
