## Simplicity Rule — one sentence per new surface

PROJECT.md binds every new control, panel or page outside Settings to a one-sentence learning reason.
Written here so the planner lifts them rather than inventing them.

| Surface | The one sentence |
|---|---|
| Home next-step block (D-01, D-02) | Retrieval beats re-reading, so the first thing a returning learner reads is the review that is due, not a blank topic box. |
| Due pill in six headers + Home nav (D-03, D-04) | A review the learner cannot see is a review they do not do; the count follows them so the forgetting curve is never out of sight. |
| Atlas retention block (D-06, D-07, D-08) | A learner who can see that about 23 of 31 nodes are held right now has a reason to review that no streak or badge can fake. |
| Stability tint (D-09) | Growth is the point and it is invisible in a binary locked/not-locked map: the gold deepening over weeks is the only honest picture of memory getting stronger. |
| `?` help overlay (D-12) | Answering from the keyboard only helps if the learner knows the keys for the card in front of them, named at the moment they ask. |
| Focus mode (D-14) | One card and the prose that explains it is the whole of what the learner is supposed to be thinking about. |

## Spacing Scale

Declared values (multiples of 4). Every utility named below **equals** its token's pixel value.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline padding, dot-to-label gap (`gap-1`) |
| sm | 8px | Compact spacing (`gap-2`) — sparkline bar gap, help-overlay row gap |
| md | 16px | Default spacing (`gap-4`), card inner `px-4`/`py-4`, overlay footer `mt-4` |
| lg | 24px | Section padding (`gap-6`, `mt-6`), help-overlay panel `px-6` |
| xl | 32px | Layout gaps (`px-8` at md), sparkline strip height (`h-8`) |
| 2xl | 48px | Major section breaks (`mt-12`) |
| 3xl | 64px | Page-level spacing (`mt-16`) |

**Exceptions — every one is a shipped value this phase reuses verbatim. This phase introduces no new
off-scale value.**

- **Multiples of 4 outside the seven tokens, already shipped:** `gap-3`/`mt-3`/`py-3` (12px — the
  next-step rows, the help-overlay column gap, the sparkline top margin), `px-5`/`py-5`/`gap-5` (20px —
  every page header's `px-5`, the help-overlay `py-5`, the next-step block's `pt-5`), `h-7` (28px — the
  focus strip), `pt-4` (16px) / `pb-24` (96px) / `pt-9` (36px) on existing shells.
- **Tailwind half-steps (a pre-existing 2px sub-rhythm, 6/10/14/18px).** The surfaces this phase extends
  are built on them and matching the sibling element is the point: `gap-1.5` (6px — the due pill's
  icon-to-count gap, matching the shipped cost pill at `Lesson.tsx:158`), `gap-2.5`/`py-2.5` (10px — the
  card eyebrow rows and Atlas list items), `px-2.5` (10px — the due pill, byte-identical to the cost
  pill), `gap-3.5`/`py-3.5` (14px — Home index rows, graph-node option rows), `pt-[18px]` (18px — the
  **literal** shipped top padding of the Atlas aside's second block at `Atlas.tsx:181`, which the
  retention block copies so the three blocks share one rhythm).
- **Hit areas:** primary buttons and fields `h-9`/`h-10` (36–40px); quiet text actions `h-8` (32px,
  the project floor from Phase 2); status/info pills `h-6` (24px — the due pill); icon-only targets keep
  a 44px hit area on mobile.
- **Radii:** cards and overlays `rounded-[18px]`; the Atlas aside `rounded-[18px]`; inputs and option
  buttons `rounded-xl`; pills `rounded-full`; sparkline bars `rounded-[2px]`.

**Hard rule for the executor:** a new element's spacing comes from the seven tokens or from the exception
list above. If a new surface needs a value that is in neither, the surface is wrong, not the scale.

## Color

Warm monochrome on near-black, from `@theme` in `web/src/index.css`. **No new token is added.**
Phase 6 owns theme, accent, font and size; every value below is referenced through its `--color-*`
variable (or a `color-mix()` against one), never as a literal hex in a component, so Phase 6 can re-skin
by swapping the token behind an `<html>` attribute.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `ink-950` `#0e0c0a` | Page background; `ink-900`/`850`/`800` for raised surfaces |
| Secondary (30%) | `ink-900/85`–`ink-900/92` over `ink-950` | Cards, the Atlas aside, the help-overlay panel, `hairline` borders (`ink-100/8`), `ink-700`/`800` for inputs |
| Accent (10%) | `gold-500` `#e8b04b` | See reserved-for list — never "all interactive elements" |
| Destructive | `rust-500` `#c9785a` / `rust-400` `#d98b6a` | Error lines and refusals only |

Secondary semantic tokens (restrained, all pre-existing):

- `teal-400` `#7fc4c9` / `teal-500` — **review and in-flight**: the next-step lead row's count, the Atlas
  due block and its `Start a review` button, the 14-day forecast bars, the `teaching` node state,
  `pulse-ring`.
- `moss-400` `#9fbc86` — a succeeded readout and the live-connection dot.
- `ink-400`/`ink-500` — every informational readout, including the due pill.

**Accent (`gold`) reserved for, after this phase:** the primary action fill (`Answer`, `Looks right,
teach me`), the locked node fill **and its stability ramp**, `locked`/`shaky` node pills, the locked
count in every header, the streaming status dot, prose links, `::selection`, `.glow-gold`, the
`complete` card, and the Atlas retention block's eyebrow plus its estimated-knowledge figure. Nothing
else takes gold.

**Two colour calls this phase makes, with their reasons, because both could reasonably have gone the
other way:**

1. **The due pill is grey, not teal.** D-04 locks "grey and small" for the lesson header, and
   §Shared Page Header extends that to all six headers and Home's nav for the "one element, one place to
   change" reason D-03 gives. Teal stays bound to the places where the learner is actually *choosing* to
   review. A pill that reads as a nudge on all six pages would be a nudge nobody can dismiss, and LEARN-17
   (reminders and notifications) is explicitly deferred to v2.
2. **True retention is never coloured as a verdict.** The figure renders `ink-100` whether it is 72% or
   96%, with `target 90%` in `ink-500` beside it. Below-target retention is not a failure — FSRS simply
   shortens intervals — and painting it rust would make the one honest number in the app read as an
   accusation. Rust in this phase is reserved for the retention-read **error** line and nothing else.

### Stability tint ramp (D-09, D-10) — the one new colour computation

Recorded discretion: "which stability values map to the faintest and the most solid gold, and whether
the ramp is linear in stability or in `log` days. Use `color-mix()` against `--color-gold-500`."

**Resolved: logarithmic in stability-days, over the 70–100% band only, so the dark node text keeps
≥4.5:1 at every point on the ramp.** Measured in oklab against `#17130b` (the shipped locked-node text):
70% gold → 4.83:1, 100% gold → 9.47:1. A ramp that reached down to 20% gold would cross a dead band at
60–65% where **neither** `#17130b` (3.77:1) nor `ink-50` (4.36:1) passes 4.5:1 on 13.5px medium text, so
the faint end is bounded at 70% rather than letting "faint" break the label.

```
t    = clamp(Math.log1p(stabilityDays) / Math.log1p(180), 0, 1)
fill = color-mix(in oklab, var(--color-gold-500) {70 + 30*t}%, var(--color-ink-850))
border = color-mix(in oklab, var(--color-gold-400) {60 + 40*t}%, var(--color-ink-700))
glow = 0 0 34px -6px color-mix(in oklab, var(--color-gold-500) {55*t}%, transparent)
ordinal = rgb(23 19 11 / {0.75 - 0.20*t})
text = #17130b   // constant at every t
```

| stability | t | fill | computed hex | contrast vs `#17130b` |
|---|---|---|---|---|
| 0 d (just locked) | 0.00 | 70% gold | `#a27c3a` | 4.83:1 |
| 14 d | 0.52 | 86% gold | `#c79743` | 7.01:1 |
| 60 d | 0.79 | 94% gold | `#daa548` | 8.35:1 |
| ≥180 d | 1.00 | `gold-500` | `#e8b04b` | 9.47:1 |

- **Two channels carry the signal:** the fill *and* the glow. The glow is the safer of the two (it is
  shadow, not text background) and it carries the full 0→55% range, so a freshly locked node has no halo
  and a months-held node glows exactly as every locked node does today.
- **`animate-glow-in` is not applied when `stability` is given.** That animation is the "just locked"
  celebration and its end state is the full 55% halo; on the Atlas it would animate every node to a glow
  the ramp says it has not earned. The in-lesson graph — which per D-10 never receives `stability` —
  keeps the animation unchanged.
- **D-10's byte-identical clause is a renderable property, not a hope:** with `stability` absent,
  `t` is not computed and the shipped class strings (`bg-gold-500 border border-gold-400 glow-gold
  animate-glow-in`, ordinal `text-[#17130b]/55`) are used verbatim. `due`, `shaky`, `teaching` and
  `pending` branches are untouched at every `t`.
- **Documented contrast exception:** the 9.5px ordinal badge sits at ~3.0:1 at `t=0` even with the alpha
  ramp. It is a decorative ordinal whose value is repeated at full contrast in the `.node-pop` hover
  panel, so no information is reachable only through it. This is the shipped situation on `gold-500`
  today, not a regression introduced here.
- **Legend (D-09's one added line).** A fifth item in the Atlas aside legend row: two 6px dots, one at
  70% gold and one at `gold-500`, then `held longer`, with
  `title="Locked nodes deepen as FSRS stability grows: pale gold is freshly locked, solid gold has held for months."`
  Short label plus a full `title` is the shipped legend pattern (`Atlas.tsx:198`).

**`Esc` precedence — one key, one documented order, evaluated top-down:**

1. the help overlay is open → close it
2. focus mode is on → leave focus mode
3. a turn is in flight → stop the turn (the Composer's existing stop action)

This is why the overlay footer and the `stop the tutor` row can both name `Esc` without ambiguity: with
the overlay open, rule 1 holds; the row describes what `Esc` does once the overlay is gone.
