The error you throw away is exactly second order

You already said this: the gap grows like the squared step, scaled by how fast the gradient changes. Let me make it exact, because we are about to lean on it hard. Walk from x to x + d along a straight line and accumulate the true change:

f(x + d) − f(x) = ∫10 ∇f(x + td)⊤d dt

Read the right-hand side. The error is built entirely from how much the gradient drifts as you walk. Which means, and this is the move the whole lesson turns on: if I can bound how fast the gradient drifts, I can bound the error.
